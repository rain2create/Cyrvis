# CYRVIS demo assets

`cyrvis-coding-demo.gif` is a silent 7.5 second, 960×540 coding-agent demo used on
the repository homepage.

It is an illustrative render, not a screen recording. It uses the actual CYRVIS brand
mark and the same heart curve as the generated `heart.py`; the UI cards are a stylized
walkthrough of the flow (voice prompt → coding agent → turtle output).
